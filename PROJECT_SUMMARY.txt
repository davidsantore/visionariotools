PROJECT OVERVIEW
----------------
Visionario Hub é uma plataforma profissional de consulta de dados com tema dark,
autenticação social (Discord/Google), dashboard intuitivo e sistema de planos
integrado com Mercado Pago.

TECHNOLOGIES USED
-----------------
Frontend:
  • React 18.3 com TypeScript 5.5
  • Tailwind CSS 3.4 para styling dark-theme
  • React Router v6 para navegação
  • Axios para requisições HTTP
  • Lucide React para ícones
  • Vite 5.4 para build otimizado

Backend:
  • Supabase (Database + Auth)
  • PostgreSQL com Row Level Security
  • Edge Functions para serverless
  • Mercado Pago API para pagamentos

PROJECT STRUCTURE
-----------------
src/
├── components/       # Sidebar, Header

DATABASE SCHEMA
---------------
Tables:
  • profiles      - Dados do usuário (1:1 com auth.users)
  • plans         - Planos de assinatura
  • modules       - Módulos de API disponíveis
  • subscriptions - Assinaturas de usuários
  • user_modules  - Acesso de usuários aos módulos
  • api_calls     - Histórico de consultas

All tables have RLS enabled for security.
